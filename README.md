# Поля — блокнот автора

Офлайн-first Android-приложение для писателей: быстрый редактор без лишнего интерфейса, папки и тома записей, примечания, импорт/экспорт и генератор литературных идей.

## Возможности

- **Два типа записей:** обычный текстовый документ и игровая запись.
- **Организация:** папки, тома, переименование и отдельные примечания к папкам, томам и документам.
- **Игровой режим:** обычный жанр или гибрид двух разных жанров; краткое описание; три случайных русских существительных в начальной форме; повторная генерация.
- **Каталог жанров:** обширная подборка традиционных, экспериментальных и намеренно необычных жанров. Гибриды образуются из пар жанров.
- **Импорт:** TXT, Markdown, HTML, DOCX, ODT, JSON, CSV, XML, RTF, LOG, YAML, INI и TeX. DOCX/ODT импортируются из текстового раздела документа; сложные макеты и изображения не переносятся.
- **Экспорт:** TXT, Markdown, HTML и JSON.
- **Офлайн-хранение:** записи автоматически сохраняются в локальном хранилище приложения на устройстве.

> Это текстовый блокнот, а не полноценный редактор Microsoft Word. Импорт PDF, старого бинарного DOC и сложных документов с таблицами/изображениями не гарантируется. Перед импортом важных файлов сохраняйте резервные копии.

## Запуск веб-версии

Требуется Node.js 24+.

~~~bash
npm run dev
# http://localhost:4173
~~~

Проверки:

~~~bash
npm test
npm run check
~~~

## Сборка Android APK

Требования: JDK 17, Android SDK Platform 35 и Gradle 8.9+.

~~~bash
npm run android:apk
~~~

APK появится в android/app/build/outputs/apk/debug/app-debug.apk.

GitHub Actions автоматически собирает APK при push, pull request или ручном запуске workflow **Build Polya Writer APK**. После успешной сборки APK можно скачать из Artifacts под именем **polya-writer-debug-apk**.

## Данные и приватность

Тексты хранятся локально в приложении и не отправляются на сервер. Очистка данных приложения или удаление браузерного хранилища может привести к потере записей — используйте экспорт для резервного копирования.
